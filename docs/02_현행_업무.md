# 현행 업무: 지금은 점심 메뉴를 이렇게 정합니다

## 지금의 흐름

1. 11시 40분쯤 누군가 팀 메신저 단톡방에 "오늘 뭐 먹지?"를 올립니다.
2. 팀원들이 각자 먹고 싶은 메뉴를 하나씩 답합니다.
3. 의견이 갈리면 누군가 메신저 투표를 엽니다.
4. 투표가 끝나면 막내가 식당에 자리가 있는지 전화로 확인합니다.
5. 자리가 없으면 2번으로 돌아갑니다.

## 불편한 점

| 불편한 점 | 자주 나오는 말 |
|---|---|
| 정하는 데 오래 걸림 | "벌써 12시 5분이에요" |
| 가격을 몰라서 다시 물어봄 | "거기 얼마였죠?" |
| 거리를 몰라서 다시 물어봄 | "거기 멀지 않아요?" |
| 늘 가던 곳만 감 | "또 김치찌개요?" |
| 혼자 먹을 곳 찾기 어려움 | "혼자 가도 되는 데 있어요?" |
